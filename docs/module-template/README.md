# Module Template

ไฟล์ในโฟลเดอร์นี้เป็น `.stub` สำหรับ copy ไปสร้าง backend module ใหม่

ให้ replace placeholder เหล่านี้:

| Placeholder | ความหมาย | ตัวอย่าง |
| --- | --- | --- |
| `Example` | ชื่อ class แบบ StudlyCase | `Product` |
| `example` | ชื่อ folder/route แบบ lowercase | `product` |
| `examples` | ชื่อ route/table แบบ plural ถ้าต้องการ | `products` |
| `tb_example` | ชื่อตาราง | `tb_product` |
| `Example Management` | ชื่อหน้า | `Product Management` |

แนะนำให้อ่าน `docs/backend-module-guide.md` ก่อน copy
